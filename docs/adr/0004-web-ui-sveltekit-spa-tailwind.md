# The web UI is a SvelteKit single-page app styled with Tailwind

The web UI uses SvelteKit 3 in SPA mode (`adapter-static` with an `index.html` fallback, `ssr = false`), served as static files by the Core with history-mode URLs, and Tailwind v4 with semantic theme tokens and no component library. SvelteKit gives one well-known place for each screen and one pattern for loading its data, so changes by people and agents don't drift. Tailwind keeps styling rules in the markup and the theme in one file. We accept about 20 KB gzipped more JS than plain Svelte (measured: 32 KB against 12 KB for a minimal app) and raised the soft JS budget to 80 KB gzipped to make room. We rejected plain Svelte with a hand-rolled router, which is smaller but leaves structure to discipline; hash URLs, which need no Core fallback but look worse; and plain CSS alone or a component library, which give agents less fixed context or add weight.
